# HTML Arcade logo

The app icon and in-app logo use a lime HTML-bracket/play mark on a near-black background.

- `html-arcade-logo.png`: final 1024 × 1024 opaque RGB PNG.
- `html-arcade-logo-original.png`: original generated image.
- `previous-app-icon.png`: the earlier placeholder icon.

Generated using the built-in ImageGen tool. The generated image was resized to the required App Store dimensions and saved without an alpha channel; the artwork was not otherwise changed.

## Final generation prompt

Use case: logo-brand. Asset type: final iOS App Store icon and small in-app logo for an original app called HTML Arcade, an iPhone player for offline HTML games. Create exactly one polished 1024 by 1024 pixel square icon, full bleed opaque near-black background (#0E1110), never a rounded-square icon placed on a white canvas. The single centered mark is bold electric lime (#CFF56D): a distinctive simple game-controller-like emblem built from two balanced HTML angle brackets < and > framing a central play triangle. Merge the coding and arcade ideas into one compact, readable silhouette with generous negative space; geometric, precise, flat vector-like edges, high contrast, very legible at 32 pixels, equal optical balance, the emblem fills about 65 percent of the canvas. Premium restrained app identity, not a stock gamepad with lots of buttons. No words or lettering, no border, no shadows, no glow, no gradients, no 3D, no device mockup, no extra symbols, no watermark, no Pokémon or Nintendo imagery. The outer square must extend fully to the image edges with no pre-rounded corners because iOS applies its own mask.
